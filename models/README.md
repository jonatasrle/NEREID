# Baseline checkpoint

`best.pt` is the YOLOv8n checkpoint fine-tuned for the single class `marine_debris`.

- Training: TrashCan-Instance, 6,065 images, 30 epochs, image size 640.
- Selection: best validation mAP50–95, epoch 30.
- Framework: Ultralytics 8.4.218.
- SHA-256: `9eb3076e234e5f8c792709d251af59a6db2d8e575883ea39101588d1710e9c32`.

The recorded experiment and validation limitations are in
[`reports/baseline`](../reports/baseline) and the main README.
